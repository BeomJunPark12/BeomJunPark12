BUTTON (PC/Mobile)

사용자의 주요 액션을 유도하고 상호작용을 돕는 컴포넌트입니다.

Solid

주요 액션에 사용되는 배경색이 채워진 형태의 버튼입니다.

Size = Small, Medium, Large
Color = Primary, Secondary
Icon = Default, Icon
Shape = Default, Rounded
Status = Default, Hovor, Disabled

Outlined

상대적으로 덜 강조해야 할 액션에 사용되는 테두리만 채워진 형태의 버튼입니다.

Size = Small, Medium, Large
Color = Primary, Secondary
Icon = Default, Icon
Shape = Default, Rounded
Status = Defualt, Hover, Disabled

Text

보조적인 액션에 사용되는 배경색이나 테두리 없이 텍스트만으로 구성된 버튼입니다.
